# Tryon Admin Dashboard

A modern, responsive admin dashboard frontend built with React, Vite, Tailwind CSS, and React Router.

## Features

- Sidebar + navbar layout with reusable components
- Pages for Dashboard, Users, Analytics, and Settings
- Dummy static data for cards, tables, and activity feeds
- Responsive design for desktop and mobile
- Placeholder chart components (swap in a chart library later)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the app at:

```
http://localhost:5173
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```
